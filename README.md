## 当前关键趋势

1. **企业 Agent 走向统一入口与治理栈。** Google 公布 Gemini agent，结合 Workspace、权限控制和模型成本路由；广泛可用性及效果待实测。
2. **防御型 AI 从漏洞发现走向运营闭环。** Anthropic 发布 Cyber Mission/OSS Scanner；未经人工预审的扫描报告须由维护者分诊。
3. **开放专用模型继续进入科学和文档工作流。** Carbon-A 发布基因候选库，LightOnOCR-3 开放布局提取模型；团队指标均待独立复测。
4. **内容来源与高风险 Agent 控制同时收紧。** OpenAI 披露伪装信源行动，Anthropic 细化使用政策；水印、人工复核和可中止机制各解决不同问题。
5. **AI 科研与行业应用投入继续增长。** 三年支持承诺、临床小样本研究与投资方观点均不等于效果或商业回报已兑现。
