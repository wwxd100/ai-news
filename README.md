## 当前关键趋势

1. **中国厂商把模型竞争升级为 Agent 全栈竞争。** LongCat-2.5 覆盖多工具长程任务，Qwen Intelligence 将规划、跨应用执行与移动创作交付给手机厂商。
2. **具身多模态开始输出可执行空间表示。** Perceptron Mk1.5 把视频推理、点框多边形和子 Agent 调度放进同一接口，但不应因此直接归类为世界模型。
3. **AI 游戏争夺生产—分发闭环。** Meta Horizon Create/Studio 从提示词生成游戏，并让作品直接进入 Facebook、Instagram 信息流试玩。
4. **System One 决策模型成为 Agent 可插拔部件。** Kev 4B 与 Jev Router 适合路由、分类和守卫，但判断模型不能替代权限与执行层。
5. **AI 基础设施资本密度继续上升。** Nscale 获 33.6 亿美元可转债融资；合同总价值仍需与已交付收入和通电算力区分。
