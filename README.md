## 当前关键趋势

1. **Agent 竞争进入垂直流程与重复可靠性。** 行业连接器、预置技能、人工复核、成本控制和 Pass^k 正在取代单次 demo，成为企业采购的核心指标。
2. **AI 安全协调已由传闻升级为公开确认，但跨国机制仍缺位。** OpenAI 确认与 Anthropic、Google DeepMind 协作，中国反对以安全之名固化美国领先。
3. **世界模型正在分化为本地实时、长时生成和世界—动作预训练。** 帧率、持续时长、状态一致性与动作泛化需要分别评估。
4. **内容授权与抓取身份成为 AI 产品基础设施。** Cloudflare 把 Search、Agent 与 Training 分开治理，公开网页不再等同于无限制的统一授权。
5. **AI 资本同时追逐超高估值和风险基础设施。** OpenAI 新估值讨论与 AEO、物理 AI 安全、保险及数据中心互连融资表明，增长和风险正在被同时定价。
