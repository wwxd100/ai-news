## 当前关键趋势

1. **世界模型分化为互动内容与机器人控制两条路线。** PixVerse R2 强调实时可交互世界，FLUX 3 Action 强调视频—动作联合预测。
2. **语音 Agent 进入完整栈竞争。** ChatGPT Voice、Qwen-Audio 3.1 与 Nemotron 分别争夺工具执行、端到端语音和多人说话人分离。
3. **生成媒体开始“OpenRouter 化”。** Comfy Router 统一多供应商媒体模型，路由、失败回退和成本归因成为新基础设施。
4. **Agent runtime 补齐持久存储和托管调度。** Vercel Drives 与 LangChain schedules 让长期后台任务更容易，也提高权限与成本治理要求。
5. **AI 游戏应让模型负责表达、引擎负责状态。** Imagina RPG 把骰子与数值计算迁回确定性引擎，提供了比新增模型更强的架构信号。
