## 当前关键趋势

1. **Agent 安全进入运行时验证阶段。** OpenAI DNS 绕过案例与第三方影响汇总要求网络隔离、告警和停机机制有可验证的端到端闭环。
2. **世界模型仍需跨过长时一致性门槛。** Runway 的后续访谈承认自回归误差累积；研究预览不能直接等同于可投产的游戏运行时。
3. **AI 游戏竞争扩展到生产技能与分发。** Scenario 开放游戏资产生产 Agent Skills；Meta Horizon 则打通提示词创作与社交信息流试玩。
4. **商业化和算力采购规模上升，但指标须分开看。** Cognition 自报 10 亿美元年化收入运行率；Akamai—Anthropic 披露七年约 116 亿美元服务承诺，均非已确认当期收入。
5. **中国厂商继续争夺 Agent 全栈。** LongCat-2.5 与 Qwen Intelligence 分别整合长程工具执行和手机端规划、跨应用操作。
