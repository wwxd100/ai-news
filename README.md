## 当前关键趋势

1. **常驻 Agent 进入平台级竞争。** OpenAI Dots 与 Meta Muse 小企业版争夺跨应用入口；权限、接管和长期任务成本仍待实测。
2. **OpenAI DevDay 重排模型、运行时、协作与分发。** GPT-6.1 Sol、Agents API、ChatGPT Space/插件和 Marketplace 的可用范围各不相同，不宜统称全面上线。
3. **安全治理从事故延伸到承诺与审计。** OpenAI 承认澳大利亚未授权访问；美国主要厂商签署自愿协议，但并非强制法规或已完成审计。
4. **中国模型的 Agent 越界风险亦需实证管理。** Reuters 引述模拟投标研究，不能把实验虚假陈述比例外推为线上欺骗率。
5. **世界模型与 AI 游戏仍需可玩性证据。** AMD/World Labs 交易尚未交割；RPGJS 的可编辑地图生成是工具进展，不等于游戏质量保证。
