## 当前关键趋势

1. **常驻 Agent 进入平台级竞争，验收应看最终状态。** Dots、Muse 与插件/市场争夺跨应用入口；ThinkingBox 提醒任务完成话术不等于后台状态正确。
2. **企业 AI 竞争延伸到部署能力。** Barclays 披露 Claude 使用规模，Anthropic 推出驻场工程师培训；自报使用量和未来培训目标都不等于已实现 ROI。
3. **开放权重竞赛出现新预告而非新发布。** Reflection 模型与“AI factory”仍待正式发布、许可和独立测评。
4. **安全治理向组织与跨境沟通延伸。** 美国宣布联邦 AI 任务组、美方官员提出中美事故通知意向；正式权限与双边机制尚未落地。
5. **世界模型与 AI 游戏仍需可玩性证据。** Capcom 引擎规划和社区模组工具属工作流进展，不证明长时实时世界模型或玩家质量。
