1. **Agent 竞争从工具调用进入生产运行治理。** 权限审批、审计回滚、使用观测、任务验证器和隔离训练环境正在成为可持续产品资产。

3. **世界模型正在分化为本地实时、长时生成和世界—动作预训练。** 帧率、持续时长、状态一致性与动作泛化需要分别评估。
