## 当前关键趋势

1. **开放模型竞争进入推理栈与 Agent 研发流程。** Naive-N0.5-Flash 已开放权重，但 2,000 token/s 属特定八卡峰值，尚非用户常态性能。
2. **世界模型研究继续分化。** AutoWM 自报 WorldArena 分数提升，尚缺独立复测与 AI 游戏长时交互证据。
3. **Agent 安全进入公共问责与运行时验收阶段。** 澳大利亚议会要求实验室负责人出席听证；网络隔离、告警停机和第三方通知须可检验。
4. **AI 游戏的生产和渠道规则并行分化。** Meta 与 Scenario 扩张生成/分发能力，UK Games Expo 对显著 AI 生成的参展内容设限。
5. **资本承诺不可混同于已实现收入。** Cognition 年化运行率、Akamai 长期合同与 Lambda 新数据中心规划各有不同证据等级。
