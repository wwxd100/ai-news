### 1. Reflection 正式介绍 Beam

- **发生了什么：** Reflection 官方公布 Beam：5010 亿总参数、230 亿激活参数的稀疏 MoE，面向编码、推理和 Agent。可申请早期访问；官方称权重、模型卡、技术报告将在本月晚些时候发布。与 [10 月 5 日日报](2026-10-05.md)里的媒体预告相比，项目身份和规格已确认，但权重仍不可下载。
- **为什么重要 / 视角：** 产品决策、投资观察需比较许可证、可部署性、中文/工具任务、推理成本与中国开放模型；自测领先不能替代第三方复测。
- **发布时间 / 类型：** 2026-10-05；公司官方博客，未标精确时刻。
- **交叉验证 / 可信度：** 官方与 [TechCrunch](https://techcrunch.com/2026/10/05/reflection-debuts-beam-a-open-weight-ai-model-to-rival-chinese-models-at-lower-compute-cost/)均确认发布介绍及权重后续计划；高（公告）、中（规格）、待验证（性能及实际开源）。
- **趋势 / 信源：** T06 从“预告”转为“正式介绍”；[Reflection 原文](https://reflection.ai/blog/introducing-beam)。

### 3. OpenAI 发布欧盟文本溯源方案

- **发生了什么：** 官方称部分 API 模型可自愿启用 textGrain 文本水印，API 默认关闭；未来几周才会给欧盟范围内符合条件的 ChatGPT/Codex 文本加不可见水印，检测工具先对研究者开放。官方自测中改写文字会降低检测率。
- **为什么重要 / 视角：** 产品决策和知识扫盲应把“有水印信号”与“能证明作者身份/所有 AI 文本”分开；内容平台需结合 C2PA、记录与人工申诉，不宜单独依赖水印审查。
- **发布时间 / 类型：** 2026-10-05；OpenAI 官方安全技术说明，无精确时分。
- **交叉验证 / 可信度：** 技术报告链接可核方法，准确率主要为官方实验；高（方案/状态），中（实验效果），待验证（现实鲁棒性）。
- **趋势 / 信源：** T07 新实践；[OpenAI 原文](https://openai.com/index/eu-text-provenance/)。

### 4. AWS 将 GLM 5.3 加入 Amazon Bedrock

- **发生了什么：** AWS 宣布智谱 Z.ai 的 GLM 5.3 可供合格企业通过 Bedrock 托管 API 调用，支持跨区域推理、缓存和多种接口。GLM 5.3 于 8 月已发布，本次增量是渠道与服务能力。
- **为什么重要 / 视角：** 产品决策、投资观察可比较中国开放模型在国际云中的采购、合规和运维门槛；AWS 引述 Z.ai 基准不等于独立测评。
- **发布时间 / 类型：** 2026-10-05；AWS 官方云服务公告，无精确时分。
- **交叉验证 / 可信度：** AWS 与 [Z.ai 原始模型介绍](https://z.ai/blog/glm-5.3)可区分渠道上线和模型发布时间；高（渠道），待验证（真实跨区域可用性与效果）。
- **趋势 / 信源：** T06、T08 持续升温；[AWS 公告](https://aws.amazon.com/blogs/machine-learning/introducing-glm-5-3-on-amazon-bedrock/)。
