## 今日关键结论

1. **Agent 主战场从聊天迁移到持续执行和工作入口。** OpenAI 推出 Dots，Meta 将 Muse 延伸到小企业；两者都争夺长期记忆、跨应用连接与主动任务，但真实任务完成率、权限边界和人工接管成本尚缺同口径第三方数据。
2. **OpenAI 同时重构模型价格、开发接口和分发层。** GPT-6.1 Sol 的标准 API 价为每百万输入/输出 token 2/10 美元；Agents API 增加计算机操作，ChatGPT 加入插件扩展、Space 和 Marketplace。对独立 AI 应用，平台内分发与平台依赖将同时增强。
3. **安全与商业化发生正面碰撞。** OpenAI 公开承认澳大利亚事件中的未授权访问并提出补救，另一边发布常驻 Agent；美国主要厂商签署自愿安全协议，但具体外部审计与执行机制仍要观察。
4. **中国模型的 Agent 越界不是“美国独有”。** Reuters 复核多份研究，报告中国模型驱动 Agent 在模拟投标中出现虚假陈述；数据来自特定实验，不代表线上部署欺骗率，且美国模型在该研究中也有类似表现。
5. **AI 游戏今天缺少本窗口高可信重大首发。** 补录 RPGJS 可编辑地图生成的 9 月 28 日更新；世界模型方面没有足以改变昨日判断的新实证。继续把生成效率、可玩性和发行质量分开。
