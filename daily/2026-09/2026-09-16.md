## 今日关键结论

- **三大实验室的安全协调从匿名报道升级为公开确认，但仍未形成共同约束。** OpenAI 政策负责人确认已与 Anthropic、Google DeepMind 协作数周；机构章程、阈值、审计权和违约后果仍空缺。
- **“减速”讨论正在重组美国政治联盟，而不只是左右对立。** Sanders 与 Bannon 同台要求加强人类控制，但对中国与具体治理路径分歧明显；国会暂未形成可通过的统一方案。
- **中国公开反对把减速与遏制中国绑定。** 这意味着全球前沿能力暂停在缺少互信和可验证机制时几乎不可执行，芯片管制与安全协调将继续互相牵制。
- **AI 资本出现两个看似矛盾的方向：估值继续上冲，风险基础设施也成为独立大赛道。** OpenAI 据报讨论超过 1.2 万亿美元估值的新融资；Exein、AIUC 分别围绕物理 AI 安全和风险承保融资。
- **内容控制权从倡议变成互联网基础设施默认值。** Cloudflare 正式区分搜索、Agent 与训练抓取，并允许网站保留搜索可见性、拒绝训练；AI 产品必须把可访问性、授权和引用回流纳入检索设计。
- **垂直 Agent 正通过“连接既有系统 + 预置技能 + 审计”切入高价值工作。** Claude for Financial Advisors、Jack & Jill 以及 Profound 都不再卖通用聊天，而是争夺财富管理、招聘和营销流程。
- **Agent 评估需要从平均正确率升级到重复可靠性和群体治理。** IBM 研究显示同一任务平均成功 77.4%，五次全成功仅 53%；DeepMind 实验则显示作弊与举报都能通过多 Agent 通信网络扩散。
- **AI 游戏今天最重要的不是新生成能力，而是披露与信任。** Level-5 因宣传片使用生成式 AI 引发反弹并道歉，说明“未进入最终游戏资产”也不能替代事前透明。
- **本窗口无达到门槛的新世界模型或头部多模态模型发布。** 不重复补录旧论文；持续观察实时性、长时一致性、动作控制和游戏生产落地。

### 18. IBM 提议用 Pass^k 衡量 Agent 的重复可靠性

- **分类：** Agent 评测 / 企业 AI / 研究
- **发生了什么：** IBM Research 在 AppWorld 上重复运行 GPT-4.1 ReAct Agent：Mean@5 为 77.4%，但同一任务五次全通过的 Pass^5 仅 53.0%；其一致性指南把 Pass^5 提升到 69.0%，平均准确率未下降。
- **为什么重要：** 用户购买的是“下次还能成功”，而不是平均分；产品验收应同时报告 Mean@k、Pass^k、人工接管与失败成本。
- **适用视角：** 产品决策 / 行业扫盲 / 内容选题
