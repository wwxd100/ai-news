## 今日关键结论

- **模型竞争正在上移到编排层。** Sakana Fugu 用可替换的开放模型池做成本—能力路由，Salesforce 则把跨厂商 Agent 的权限、上下文、血缘和成本控制包装成企业控制平面；单一模型已不是完整产品边界。
- **Agent 安全的威胁模型必须同时覆盖“Agent 攻击别人”和“Agent 自己越界”。** PaperCut 大规模入侵、RubyGems 包投放和 coding-agent sandbox 泄漏表明，速度、并发与错误范围都会被自动化放大。
- **AI 游戏正从辅助创作进入“提示词直接生成可玩体验 + 独立分发 + 收款”的闭环。** Roblox Build 的关键不是一次生成，而是把生成、发布和创作者经济连到同一平台。
- **内容授权从防御走向产品化。** UMG 与 ElevenLabs 计划用授权曲库支持 remix、mashup 和个性化声音体验，和 Suno v6 一起构成“权利人参与、模型能力、收益分配”新路线。
- **AI 科学突破的治理开始遭遇专业共同体反弹。** 25 位菲尔兹奖得主要求完整写作、归因、同行验证与人才培养优先于实验室抢发 benchmark 式成果；这会影响 AI 科学产品的发布规范。
- **资本继续为算力和主权溢价，但交易结构越来越政治化。** Positron、澳大利亚 2GW AI factory、UAE Stargate 重构和 Cohere 融资谈判都说明，能源、地域安全、政府资金与供应链已成为模型经济的一部分。
- **“AI 促进增长”和“AI 导致裁员”可以同时成立，但现有归因仍很粗。** 英国 GDP 数据出现 AI 相关行业贡献，而美国裁员报告把相当一部分重组归因于 AI；两者都不能直接证明微观因果。

- **T01 Agent 系统：加速。** Fugu 把动态模型编排商品化，Salesforce 把控制平面商品化；竞争栈新增“路由 + 治理 + 供应链弹性”。
- **T02 世界模型：无重大新增。** 本窗口未发现足够强的一手发布；继续观察本地实时、长时一致性与世界—动作预训练三条路线，不以重复 demo 制造趋势。
- **T03 多模态生产：版权基础设施增强。** UMG–ElevenLabs 与 Suno v6 共同把授权、可编辑性和收益分配推到产品层。

## 反泡沫提醒

- 今天不少高热信息来自独家报道、厂商 benchmark 或规划容量；“正在洽谈”“计划建设”和“性能领先”均不等于已成交、已投产或经第三方验证。
- PaperCut 与 RubyGems 事件显示 Agent 风险真实存在，但不能从单次攻击直接推导所有 Agent 都会自主失控；关键变量是权限、账户治理、外部工具和人工复核。
- Roblox Build 的扩区不证明提示词游戏具有长期留存。真正需要观察的是完成率、次日留存、人工编辑比例、内容审核成本和创作者收入分布。
- 英国 GDP 与美国裁员数据使用不同口径，不能合并成一个“AI 净创造/净消灭多少岗位”的结论。
- 本窗口没有新的高质量世界模型发布。缺乏新闻本身不是路线停滞，也不应拿旧 demo 填充“每日进展”。
