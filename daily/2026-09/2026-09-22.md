## 今日关键结论

- **Grok 4.7 把前沿竞争重新拉回“长任务能力 × 价格”。** xAI 在与 4.6 同价的前提下更换更大底模、延长强化学习并增强自检；厂商分数显示它在部分工程任务接近前沿，但 Terminal-Bench 与医疗任务仍落后头部。
- **中国 Agent 产品今天的重点不是再发一个聊天模型，而是桌面工作台和完整内容生产线。** Kimi Code Desktop 管理并行编程 Agent，BytePlus Dramagic 把剧本、资产、分镜和预览接成短剧工作流。
- **创意工具正在从“生成入口”变成“可编辑生产环境”。** ElevenLabs Studio 4.0、Runway Workflows、Krea MCP 和 Perplexity Computer 分别占据时间线、节点管线、Agent 协议和一体化交付入口。
- **Agent 基础设施出现 Kubernetes 化和终端化两条路线。** Google AX 面向集群编排，Devin Cloud 把创建、恢复和 SSH 带进 CLI；运行时、隔离、状态和可观测性正在成为产品核心。
- **开放模型的瓶颈正在从权重可得性转向结构化输出和推理工程。** DeepSeek V4.1 严格工具调用、Qwen3.8 分离式 prefill/decode、NVFP4 KV cache 都在压缩生产失败或显存成本。
- **“决策模型”正在快速从单一 Jev 产品变成协议和生态。** Kev 开放权重、LangSmith Gateway 支持 System One、WebMCP 扩展把它用于实时工具预测；但封闭分类成功仍不等于开放 Agent 可靠。
- **OpenAI 同时加强国际标准叙事和数学研究外部监督。** 前者建议借助各国安全机构协调标准，后者让独立数学家可公开评论；关键仍是成员独立性、访问权限和建议是否约束发布。
- **SoftBank 的 OpenAI 押注开始把 AI 估值风险更直接传导到信用市场。** 据报计划发行约 110 亿美元高收益债，融资成本与集中度应与模型增长叙事一起评估。
- **真实用户反馈仍提醒“能运行”远不等于“可交付”。** Arena 的 20,840 条编码 Agent 轨迹中，69.1% 投诉仍指向代码损坏；文档、抛光和验证成为下一层竞争。
- **世界模型今日无旗舰发布；AI 游戏的新增信号来自可发布形态。** Craft 把 AI RPG 会话导出为可编辑视觉小说，说明“生成内容如何变成可消费作品”比继续堆叙事长度更值得跟踪。
