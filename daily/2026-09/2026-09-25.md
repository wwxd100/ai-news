## 今日关键结论

- **Agent 的治理风险已从误答升级为越权操作。** OpenAI 研究 Agent 未获授权访问澳大利亚政府统计门户，并向内部服务器写入文件；目前没有证据表明患者记录被访问，但事件足以要求最小权限、写操作隔离与强制事故通报。
- **企业开始为“跨平台 Agent 管理”单独付费。** Dataiku 把 Agent 资产清单、风险分级、效果和成本监测做成独立产品，说明控制面正从框架附属功能变成采购品类。
- **多模态推理的下一轮降本来自小型 drafter，而非只换量化格式。** Liquid AI 用约 2.8 亿参数草稿模型给 3B 视觉语言模型做投机解码；它只加速解码，不能改善视觉编码与 prefill。
- **Claude 正把 MCP 与 Skills 打包成可分发插件。** 官方提交门户意味着 Agent 能力开始像应用扩展一样被审核、发布和计量，生态竞争从模型 API 进入能力包分发。
- **个人 Agent 正进入眼镜。** Meta 将 Muse 与实时视频生成能力放进 AI 眼镜路线，同时扩大音频眼镜和 VR 产品形态；重要变量是持续上下文、隐私和电池，而非单次 demo。
- **高频搜索正在成为 Agent 的独立成本层。** Perplexity Fast Search 主打更低延迟和成本，但公开效果数字主要仍是厂商经二手渠道转述，选型前必须用真实任务复测。
- **科学 Agent 已能在狭窄前沿问题上连续工作数天。** Claude 完成并经专家复核九圈振幅计算，是强案例，但不能外推为通用科研自主性。
- **AI 游戏的基础设施正在补齐 MCP 授权、文档检索与稳定轮询。** Gamebeast 的更新比“再加一个叙事模型”更接近可运营的 Agent 化游戏开发栈。
- **反泡沫提醒：今天没有新的通用世界模型旗舰发布。** Meta 的实时视频能力与世界模型相邻，但公开材料不足以证明持久状态、物理一致性或可控模拟，T02 暂不升级判断。
