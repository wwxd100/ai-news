## 今日关键结论

1. **通用模型进入蛋白质设计流程，但尚未端到端替代专用模型。** OpenAI 披露 GPT-6.2 参与设计的 322 个迷你结合蛋白中 35 个在五类目标的实验中呈结合阳性；序列补全与候选筛选仍用专用模型。结合不等于药效。
2. **可靠性评测开始关注重复与轻微变体。** Google 推出 Humanity’s First Exam，用 544 个基础文本/图像题测 20 类能力的稳定性；现阶段分数不能直接推断真实业务可靠性。
3. **前沿模型可发布性争论升温，但内部能力报道仍是匿名信源主张。** Axios 采访二十多名知情者；OpenAI 和 Anthropic 对流程作回应。不能由报道断言未发布模型已失控。
4. **Agent 的价值开始落到数据作业调度和可复核的任务成本。** Zipher 披露新一轮 4500 万美元融资，5300 万美元是含旧种子轮的累计额；Marlowe 前日公布 2.77 亿美元种子融资，试图按推理负载搭配不同芯片。两者的节省数字与交付能力均需客户侧复测。
5. **具身与科学 Agent 出现可执行案例，但验证层级不同。** NVIDIA 给出 Microduck 仿真到真机避障流程；OpenAI 披露利用 Codex/Astra 搜索系外行星候选，候选尚未确认为行星。

## 高信号动态

### 1. OpenAI 披露 GPT-6 系列的蛋白质设计实验

- **发生了什么：** OpenAI 与 Onava 对 GPT-6.2 生成的设计做实验：322 个迷你结合蛋白、5 个目标中，35 个显示结合阳性。蛋白质序列提议和候选筛选仍借助 SolubleMPNN 等专用模型；论文也明确尚未证明无需专用模型的端到端零样本设计。
- **为什么重要 / 视角：** 产品决策、投资观察、知识扫盲。通用模型可承担结构草案和约束推理，但科学产品应把候选生成、湿实验、活性与安全分成不同验收阶段。
- **发布时间 / 类型 / 原始信源：** 2026-11-24，OpenAI [研究文章及论文入口](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/)，公司研究与合作实验。
- **交叉验证 / 可信度：** 实验属于合作团队报告，尚缺独立重复；发表和方法边界高可信，泛化与药物价值待验证。
- **趋势：** T01/T07 持续升温；通用模型科学任务从计算基准进入有限湿实验。

### 2. Google 推出 Humanity’s First Exam 可靠性评测

- **发生了什么：** Google DeepMind 在 Kaggle 推出 HFE，含 544 个基础文本与图像提示，覆盖 20 类能力，强调同一任务及轻微变体的连续正确性，并开放社区征题至 12 月 15 日。
- **为什么重要 / 视角：** 产品决策、内容选题、知识扫盲。设计 Agent 或内容审核时，应测多次执行及边界变体的失败率；不能把某次成功或单个榜分当成稳定交付。
- **发布时间 / 类型 / 原始信源：** 2026-11-24，Google [官方介绍](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/humanitys-first-exam/)及其链接的技术报告和 Kaggle 榜单，发布方研究资料。
- **交叉验证 / 可信度：** 数据集和入口可核查；该基准对实际工作流的预测力未获独立验证。发布高可信，效用待复测。
- **趋势：** T01/T07 首次出现；可靠性从单次能力转向重复稳定性。

### 3. Axios 报道前沿实验室对未发布模型的安全分歧

- **发生了什么：** Axios 称采访二十多名了解 OpenAI、Anthropic 内部讨论的人士，报道部分研究者担心更强模型难以安全发布。OpenAI 发言人称已采用可能放慢发布的新安全要求；Anthropic 发言人称可能在付出成本时放缓或暂缓。内部模型能力细节未有公开工件供外部核查。
- **为什么重要 / 视角：** 产品决策、投资观察、内容选题。模型路线图和供应风险需考虑评测、访问控制与发布节奏；匿名说法不应写成模型已失控的事实。
- **发布时间 / 类型 / 原始信源：** 2026-11-24，Axios [独家报道及两家公司回应](https://www.axios.com/2026/11/24/anthropic-openai-unreleased-ai-safety-risks)，媒体采访。
- **交叉验证 / 可信度：** 多名匿名知情者和具名公司回应支持“存在争论”的报道；具体未发布能力和风险没有独立公开验证。中可信。
- **趋势：** T07 持续升温；高能力模型的可发布边界待验证。

### 4. Zipher 新融资 4500 万美元，累计融资 5300 万美元

- **发生了什么：** 公司新闻稿称种子轮与 A 轮合计 5300 万美元；Ctech 独立采访明确本次 A 轮为 4500 万美元，2024 年种子轮为 800 万美元。产品让 Agent 在客户设定的 SLA 与预算下选择数据处理引擎、资源和调度。
- **为什么重要 / 视角：** 投资观察、产品决策。企业 Agent 的基础设施机会从对话层延伸至后台数据任务；应按真实作业的成本、SLA、错误恢复与人工接管测量。
- **发布时间 / 类型 / 原始信源：** 2026-11-24，[公司新闻稿](https://www.businesswire.com/news/home/20261124091381/en/)及 [Ctech 独立采访](https://www.calcalistech.com/ctechnews/article/bkreuwq1xg)，公告与媒体。
- **交叉验证 / 可信度：** 融资口径可交叉核对；公司宣称的客户节省和 SLA 提升缺公开独立任务数据。融资中高可信，绩效待验证。
- **趋势：** T04/T08 首次出现；Agent 运行基础设施受资本关注。

### 5. NVIDIA 发布 Microduck 仿真到真机避障流程

- **发生了什么：** NVIDIA 在 Hugging Face 给出用 Isaac Lab、Newton、ToF 传感器训练 Microduck 避障控制器的教程，保留原有行走策略，另训导航策略，并说明 ONNX 导出和真机测试步骤。文中的并行环境数是配置示例，不是最低硬件门槛。
- **为什么重要 / 视角：** 产品决策、知识扫盲。拆分行走与避障有助于定位失败和复用底层策略；教程可复现性、真机碰撞率与跨场景泛化仍需独立测量。它是机器人控制流程，不是游戏世界模型。
- **发布时间 / 类型 / 原始信源：** 2026-11-24，NVIDIA [Hugging Face 教程](https://huggingface.co/blog/nvidia/microduck-obstacle-avoidance)及其中链接的代码，官方技术资料。
- **交叉验证 / 可信度：** 代码与步骤可检查；本文无独立真机规模评估。交付高可信，效果待复测。
- **趋势：** T02/T05 持续升温；具身工作流从模型演示走向仿真与部署配套。

### 6. OpenAI 披露 Astra 辅助业余天文学家寻找系外行星候选

- **发生了什么：** 两名研究爱好者借助 Codex/Astra 编写并运行公开望远镜数据搜索流程。一名 SETI 研究者用独立搜索找到其中两处相同信号；另一批候选已交天文学团队进一步分析。信号尚未确认为系外行星。
- **为什么重要 / 视角：** 内容选题、知识扫盲、产品决策。这是 Agent 帮助非专业人士建立研究流程的案例；应保存代码、原始数据、假阳性排查和外部复核记录，避免把候选写成发现。
- **发布时间 / 类型 / 原始信源：** 2026-11-24，OpenAI [案例文章](https://openai.com/index/searching-for-distant-planets-with-astra/)，参与方一手叙述。
- **交叉验证 / 可信度：** 文章引用 SETI 研究者对两处信号的独立检查，仍需后续观测与同行评议。候选和核查过程可信，行星结论待验证。
- **趋势：** T04/T07 持续升温；科学 Agent 的产物进入外部核查环节。
