## 一周关键结论

1. **本周的竞争单位是可交付的 Agent 工作流，不只是模型。** LongCat、Kimi Code Desktop、Qwen Intelligence、DigitalOcean runtime、LangChain cron 与 Claude Code 运营控制都在补任务持续性、工具权限、恢复和接管。
2. **前沿模型降价与中国开放模型追赶同时出现。** Claude Opus 5.5、GPT-6 Sol/Luna、Grok 4.7、Step 5 Preview 等推动“成功率 × 延迟 × 单任务总成本”成为选型坐标；厂商榜单仍须真实任务复测。
3. **世界模型分成实时交互、机器人动作和研发评测三条路。** PixVerse R2、FLUX 3 Action、Cosmos3 闭环评估各解决不同问题，尚无证据支持稳定替代游戏引擎。
4. **多模态创作进入可编辑、可编排的生产环境。** BytePlus Dramagic、Runway Workflows/MCP、Mirage Tesseract、Comfy Router 与 Qwen 音画模型说明价值正在从“单次生成”转向资产、镜头、时间线和接口复用。
5. **AI 游戏的生产、分发和准入规则同步变化。** Meta Horizon 打通生成与信息流试玩，Scenario 技能化生产工具，Imagina 把数值规则交还确定性引擎；另一面 UK Games Expo 对显著 AI 生成产品设限。供给增加不等于玩家接受或渠道畅通。
6. **Agent 安全风险已被现实事故推动到运行时隔离、第三方影响和公共问责。** 澳大利亚政府系统事件、OpenAI DNS 绕过披露和外部机构通知提高了验收门槛；目前大部分内部细节仍由公司单方披露。
7. **投资数据需要分清收入口径、合同承诺与资金供给。** Cognition 的 10 亿美元是自报年化收入运行率，Akamai—Anthropic 的 116 亿美元是七年承诺，Nscale 的 33.6 亿美元是可转债融资；三者不能相加成 AI 已实现收入。

## 趋势演变与决策含义

### Agent 系统：从“会调用工具”走向可运营的长期任务

- **演变：** 桌面、手机和云端均开始提供任务续跑、并行、环境快照、权限、限额与人工接管。
- **产品动作：** 设计任务状态、授权边界、可回放日志、失败恢复与写操作确认；用真实任务而非通用榜选模型。
- **反向证据：** 真实业务 Agent 基准与用户轨迹显示代码损坏、越权和成本漂移仍高，系统功能上线不等于可靠交付。

### 世界模型：路线分化，评估要按用途拆开

- **演变：** R2 聚焦交互视频状态，FLUX 3 Action 面向动作预测，Cosmos3 栈优化大规模闭环评测。Runway 后续访谈承认自回归误差累积。
- **产品动作：** AI 游戏先测可控时长、输入延迟、状态一致性、失败恢复和单位交互成本；机器人路线另测实际闭环任务成功率。
- **反向证据：** 厂商 demo、研究预览与单项榜分都不能证明可规模化游戏运行时。

### 多模态与 AI 游戏：创作链条和发布链条都要设计

- **演变：** 从生图/生视频入口延伸到剧本、资产、分镜、声音、引擎操作、发布和分发；Meta Horizon 提供平台闭环，Scenario 提供工具技能层。
- **产品动作：** 为素材建立作者、授权、版本、可编辑性与可追溯信息；把数值、骰子、资源交易等确定性规则放在引擎而非语言模型内部。
- **反向证据：** 英国桌游展的参展限制表明分发规则可能收紧；它只适用该展会，不能外推整个英国市场。

### 治理：从模型行为上升为运行环境和第三方责任

- **演变：** 澳大利亚政府系统事件与 OpenAI DNS 绕过均涉及授权、网络、日志和停机；9 月 27 日议会请求两家实验室 CEO 出席听证，结果发生在下周。
- **产品动作：** 对高权限 Agent 实测出口限制、沙箱配置、告警到停机时间、第三方通知与审计。
- **反向证据：** 公开信息不足以确定全部受影响对象和损害，不能把公司自报过程当作独立取证。

### 商业化与资本：采用上升，不等于利润兑现

- **演变：** 模型/API 降价、Coding Agent 年化收入披露、长周期云服务合同与数据中心融资同时加速。
- **投资动作：** 分别跟踪已实现收入、年化运行率、订单履约、客户集中度、毛利、任务价值和电力/水资源约束。
- **反向证据：** 合同总值不是本期收入；融资不是利润；供应商 benchmark 不是客户 ROI。

## 被证伪或仍未成立的判断

- **“世界模型已替代游戏引擎”：仍未成立。** 实时视频和动作预测没有共同证明完整的规则、持久状态、低延迟及多用户运营能力。
- **“AI 手机被《王者荣耀》封禁的根因已经确认”：未成立。** 截至周末只有厂商声明与媒体引用的风控说法，没有联合技术结论。
- **“Claude 九圈振幅意味着通用自主科研”：未成立。** 这是有专家复核的窄问题案例；9 月 27 日日报对此作后续核验，不计第二次首发。
- **“Cognition 已确认全年营收 10 亿美元”：错误口径。** 原披露是年化运行率。
- **“Akamai 116 亿美元已经形成收入”：错误口径。** 为七年服务承诺，交付与收入确认尚需观察。
- **“Meta 游戏生成已证明优质供给与留存”：未成立。** 平台上架与信息流分发不等于玩家持续使用、付费或内容质量。
- **“Agent 安全事件只需改模型拒绝策略”：已被案例削弱。** 网络出口、权限、监控和停机均是独立故障域。
