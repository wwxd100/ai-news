## 一周结论

1. **AI 治理从行业倡议迅速分裂为联邦加速、州级强监管、跨实验室安全合作和司法挑战。** “AI Force”、加州独立核验、四家实验室协作和反垄断诉讼同时出现，说明不存在单一政策方向。
2. **实验室安全承诺开始与竞争、融资和上市压力正面冲突。** Anthropic 一边公开研发自动化与监督指标，一边被报道考虑加速新模型；OpenAI、Google 和 SpaceXAI 也面临相同张力。
3. **Agent 竞争从模型能力进入运行系统。** OpenClaw 协作、Google CC 家庭身份、AWS runtime 快照、Safari MCP、Antigravity 工具契约、AgentCloak 隐私代理和 Sentient 评分器泄漏共同把权限、恢复、验证与隐私推到前台。
4. **多模态价值从生成质量转向实时、可编辑和地域化部署。** Qwen 同传、Google Flow 时装工作流、Seedance 美国端点和局部控制说明生产管线正在取代单次 demo 成为产品单位。
5. **世界模型出现一个可操作进展，但商业透明度仍低。** Zing-0.5 证明键盘动作与文本联合控制；AMI Labs 与 World Labs 仍未给出可验证的产品、价格和时间表。
6. **开放权重与专用决策模型推动任务分层。** Vercel 单一网关中开放权重 token 占比升高，Jev 用类型化概率争夺 Agent 决策层；两者都不能外推为全球份额或长期留存。
7. **AI 游戏呈现“后台高采用、前台高争议”。** 日本开发者调查显示广泛使用，Level-5 争议与跨地区调查差异则表明最终资产、披露和玩家接受度仍是边界。
8. **企业价值证明仍落后于采用叙事。** Claude 文档入口、生命科学提速、Magentic 供应链 Agent 和 Axios enablement 提供正面案例，但临床证据、中小企业试点停滞和归因缺失仍是反向证据。

## 趋势演变

### 1. Agent 系统：从工具调用转向身份、协作、恢复与验证

- **本周变化：** 消费者 Agent、家庭 Agent、企业 Agent 和浏览器/开发工具同时增加长期状态、共享会话、专业角色与环境快照。
- **产品判断：** 应优先积累权限模型、任务状态、工具契约、可回放轨迹、失败恢复和人工接管，而不是把差异化押在单一模型。
- **反向证据：** Sentient 评分器泄漏、Gemini 授权测试越界和真实业务低成功率说明更长任务会放大错误与激励错位。

### 2. 世界模型：动作控制有进展，商业可用性仍未证明

- **本周变化：** Zing-0.5 用 5B 模型支持键盘动作与在线文本控制；开放研究继续把世界模型拆成可玩实时、长时状态和机器人泛化。
- **产品判断：** 近期更适合作为动态场景、镜头预演、训练与探索层，而不是完整游戏引擎替代品。
- **反向证据：** 头部公司的部署成本、失败恢复、长时一致性、输入延迟和收费均缺公开证据。

### 3. 多模态：实时体验、结构控制与部署地域共同决定价值

- **本周变化：** 实时同传、时装设计工作流、美国托管视频端点和高速视觉模型共同出现。
- **产品判断：** 对 Yoroll 等内容产品，场景、角色、镜头、时序、素材权利和地域数据路径比模型入口数量更重要。
- **反向证据：** 厂商演示、峰值速度和单一排行榜不能证明普通硬件成本、重生成稳定性或权利清晰。

### 4. AI 游戏：内部采用率与玩家可见结果必须分开

- **本周变化：** CESA 报告高采用率，Level-5 收紧边界，日美调查呈现差异，100 小时 AI 游戏挑战展示生产速度。
- **产品判断：** 未来披露应按代码、概念、最终资产、配音和运行时生成分层；总采用率不具备决策精度。
- **反向证据：** 调查样本、问题与统计单位不同，不能用总比例推导文化差异或玩家接受度。

### 5. 治理：安全合作需要竞争法与独立性设计

- **本周变化：** 实验室协作被公开确认，随后出现反垄断诉讼；加州推动独立核验，美国联邦政府则强调加速。
- **下一判断门槛：** 共同章程、能力阈值、事故分级、披露时限、评估者资金、公开异议权、竞争法安全港和双边事故机制。

### 6. 商业化：采用、流量和收入都需要拆口径

- **本周变化：** 开放权重 token、高价闭源支出、专用模型采用、企业组织设计和大额基础设施融资同时上升。
- **投资判断：** 应拆分试用与留存、token 与任务价值、年化速度与已实现收入、融资与单位经济。

## 本周被证伪或仍未成立的判断

- **“四家实验室已经达成可执行减速协议”：未成立。** 只有方向性公开支持与合作讨论，没有统一条款；随后还出现反垄断诉讼。
- **“Anthropic 已正式宣布下一代模型”：未成立。** 目前只有 Reuters 匿名信源称其考虑加速发布。
- **“开放权重模型已占全球 78.4% 市场”：错误。** 该数字只是 Vercel AI Gateway 最近时点的 token 份额。
- **“85.8% 日本游戏最终资产由 AI 生成”：错误。** CESA 测量的是受访开发者使用情况，未区分代码、概念图、最终资产或运行时生成。
- **“世界模型已可替代游戏引擎”：未成立。** Zing-0.5 只证明特定动作与文本控制能力。
- **“AI 药物研发的临床效果已经得到证明”：未成立。** 工程提速和模型优化不等于临床终点，Nature 评论仍强调临床证据有限。
- **“加州已强制部署模型 kill switch”：错误。** 当前是专家指南与规则讨论，不是统一生效的技术义务。
- **“Muse 登顶 App Store 证明长期留存”：未成立。** 下载榜只能证明短期分发，不证明复用、付费或长期代理价值。
- **“AI Force 已成为正式联邦机构”：未成立。** 总统表态存在，但组织、预算、权限与负责人尚未公布。
- **“Anthropic 的 1000 亿美元是已审计年收入”：错误。** 报道口径是年化收入速度，不等于完整财年收入、利润或现金流。

## 反泡沫提醒

- 本周政策与公司事件密度高，但许多仍是表态、提案、匿名信源或单平台数据。
- “安全减速”和“加速竞争”可能同时包含真实风险、监管策略、声誉与商业利益，不能用单一动机解释。
- 厂商 benchmark、App Store 排名、token 份额、年化收入速度与融资估值均不是同一种证据。
- 研发自动化比例增加不等于递归自我改进已经发生；监督覆盖和复核延迟同样重要。
- 资本继续流向算力与数据中心不证明最终回报率，只说明当前战略偏好和供给焦虑。
